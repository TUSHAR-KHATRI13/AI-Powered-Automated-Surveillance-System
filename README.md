# 📷 AI-Powered Automated Surveillance System

An advanced **AI-driven surveillance platform** that leverages state-of-the-art deep learning models for real-time object detection, classification, and alerting on live video feeds and recorded datasets.

This system enhances traditional CCTV monitoring by automating threat detection using modern computer vision techniques.

---

## 🧠 Overview

Traditional surveillance systems require constant human monitoring, which can be inefficient and error-prone. This project introduces an intelligent AI-powered system that automatically detects and classifies objects in real time.

The system integrates:

- **YOLOv8** for fast, real-time object detection  
- **Faster R-CNN** for high-precision classification  
- **Email alert integration** for immediate notifications  

By combining one-stage and two-stage detectors, the system achieves improved detection accuracy while maintaining real-time performance.

## ⚙️ Features

### 🎯 Real-Time Object Detection
Detects and classifies objects such as people, weapons, or suspicious items in live video streams.

### 📦 Dual Model Architecture
- **YOLOv8** → Fast detection
- **Faster R-CNN** → Higher classification precision

### 📬 Automated Email Alerts
Sends real-time notifications when specific objects or activities are detected.

### 🎥 Multi-Source Support
- Webcam input  
- CCTV feeds  
- Offline video files  

### 🔄 Scalable & Modular Design
Easily extendable to add:
- New detection classes
- SMS or push notifications
- Cloud deployment
- Face recognition
